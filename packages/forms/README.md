# @openuxkit/forms

Form and validation utilities for OpenVue and other OpenVi Foundation projects

Part of [OpenUXKit](https://github.com/openvi-foundation/openux), the framework-agnostic UI foundation behind [OpenVue](https://github.com/open-vue/openvue).

```bash
npm install @openuxkit/forms
```
